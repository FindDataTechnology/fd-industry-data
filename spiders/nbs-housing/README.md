# nbs-housing —— 国家统计局房地产口径（HTML 表格）

新源接入档案（`templates/new-source/` 范式）。入口：`run_nbs_housing(limit=200, dataset="all")`
（`spider.py`）。仅标准库（`asyncio/logging/re/datetime/html`）+ scrapling 系（`FetcherSession`
取页、`lxml` 解析）——无新增第三方依赖。

**与 `spiders/nbs-stats` 的边界（刻意不合并）**：该单元走 `data.stats.gov.cn/easyquery.htm`
JSON 接口 + 流通领域旬度价格；本单元走 `www.stats.gov.cn/sj/zxfb/` 文章内联 HTML 表格。
取数通道、页面形态、解析路径都不同，合并只会让两条路互相拖累。

## 数据表面

| 用途 | 端点 | 说明 |
|---|---|---|
| 发布列表 | `GET https://www.stats.gov.cn/sj/zxfb/`（+`index_N.html`） | 「最新发布」，最新在前；文章链接是相对路径 `./YYYYMM/tYYYYMMDD_<id>.html`（实测 67 页） |
| 70 城房价 | 文章 `…70个大中城市商品住宅销售价格变动情况` | 页内 12 个 `<table>` = 6 张表 ×（PC 容器 + 移动容器副本） |
| 房地产市场 | 文章 `…全国房地产市场基本情况` | 页内 3 张 PC 表：表1 全国指标、表2/表3 东中西部和东北地区 |

**板块发现优先于硬编码**：入口只从列表页按标题正则
（`70个大中城市商品住宅销售价格` / `全国房地产市场基本情况`）取**最新**一篇，
不写死任何文章 URL——文章 URL 随月份变化，写死必然失效。

## 字段口径

| 列 | 来源 | 口径 |
|---|---|---|
| `city` | 70 城表城市格 | 全角/半角空格全部剥离（`北　　京` → `北京`） |
| `housing_type` | 表标题 | `新建商品住宅` / `二手住宅`（**按表标题区分，不混类**） |
| `period` | 文章标题 | 70 城 `YYYY-MM`；房地产累计 `YYYY-01~YYYY-MM`；年度 `YYYY` |
| `mom` | 表1/表2「环比」列 | 上月=100；缺测 None |
| `yoy` | 70 城「同比」列 / 房地产「同比增长（%）」 | 70 城为上年同月=100；房地产为百分比（可为负） |
| `ytd_avg` | 70 城「1-N月平均」列 | 上年同期=100；**1 月发布无此列 → None** |
| `indicator` | 房地产表1 指标列 | 主项用括号前文本，单位另存 `unit` |
| `value` | 房地产表1 绝对量列 | float；缺测 None，**绝不填 0** |
| `unit` | 指标行括号内 | `亿元` / `万平方米` |
| `report_title` / `report_url` | 文章 | 行级来源可追溯 |
| `source` | 常量 | `nbs-housing` |
| `scraped_at` | 本地 | UTC ISO8601 |

## 坑位与容错（逐条落实并留痕）

1. **城市名含空格**：HTML 里是 `北　　京`（U+3000）、`秦 皇 岛`（半角空格）。
   统一 `re.sub(r"\s+", "", …)` 剥离后再用 `^[\u4e00-\u9fff]{2,8}$` 校验城市格；
   实测三期文章 140 行城市名零空格残留。
2. **12 张表语义不同，绝不混为一类**：PC 容器里 6 张唯一表，标题形如
   `表1/表2：…销售价格指数`（本单元列可承载）与
   `表3/表4：…销售价格分类指数（一/二）`（面积段分桶 90m2 及以下/90-144/144 以上，
   与设计列不匹配）。**分类指数表按标题识别后显式跳过并打日志**，不产出错误语义行；
   跳过而非猜测。移动容器副本按 PC 容器限定 + 标题去重双重排除。
3. **数字缺测**：`—`/`－`/`–`/`-`/`…`/`/`/空 一律记 `None`，绝不填 0。
4. **1 月发布无累计列**：表头从 8 格变 6 格。块宽由表头里两个 `城市` 格的位置推导
   （`width = city_pos[1] - city_pos[0]`），并校验 `len(header) == 2*width`，
   所以 1 月与 8 月同一套代码解析；实测 2026-01 期 140 行、`ytd_avg` 全 None。
5. **年度发布口径不同**：`2025年全国房地产市场基本情况` 表头是
   `比上年增长（%）`，period 记 `2025`；标题正则显式限定 `^YYYY年全国房地产市场基本情况`，
   认不出就跳过而不是错标。
6. **子项归属**：表1 的 `其中：住宅/办公楼/商业营业用房` 与 `国内贷款/自筹资金/…`
   只有相对上一个主项才有意义，按 `主项·子项` 命名；主项之前出现的孤立子项直接丢弃。
7. **连字符目录**：不能 `from spiders.nbs_housing.spider import …`（ModuleNotFoundError）。
   真实装载走 `fd_industry_data/loader.py:load_spider_module(src, content_dir)`；
   golden 重放走 `fd_industry_data/health/guard.py:load_unit_entry`。
8. **传送**：裸 UA 实测 200（列表页与文章页均通）；`FetcherSession(impersonate="chrome120")`
   + 固定 UA/`Accept-Language`，`retries=1`——单次尝试，**不连环重试、不绕过反爬**。
   `verify=False` 与同站 `nbs-stats` 保持一致（不假设容器信任库）。
9. **单表/单指标失败只跳过留痕**：两张表解析互不影响；文章取数异常只跳过该篇。
   全部失败返回空列表并打 warning（不抛、不重试）。

## limit 与公平配额

`limit` 是硬上限。70 城一篇就是 140 行，若简单拼接，小 `limit` 会被它吃光、房地产月度
永远不出现；因此 `dataset="all"` 时两口径公平分配（market 最多一半，用不完的份额回流给
70 城），且 70 城侧按 `housing_type` 轮转交错，保证任意 limit 下两类住宅都出现。
实测：`limit=1→1 行`、`limit=3→3 行(2+1)`、`limit=20→20 行(10+10)`、
`limit=200→175 行(140+35)`（= 全部产出）。
只想取单口径时用 `dataset="70city"` / `dataset="market"`。

## golden 断言口径（跨期稳定）

`golden/001-nbs-housing.json`（`limit=60`）只锚**结构性、跨月不变**的字段：
`source`、两种 `housing_type`、城市 `北京`、指标 `房地产开发投资`、两种 `unit`，
外加 `min_rows: 40`。

**为什么不锚数值**：本单元取的是「最新发布」，锚 `99.8`/`47979` 之类当月值下个月必然
失效——那会把正常换月变成假故障。真实数值的证据在本文档「实测样例」与 README 下的
实弹复测里（`99.8 / 97.7 / 47979 / 560770 / 29894 / 21097`），并已由
`run_nbs_housing(limit=200)` 的实取输出复核。

## 历史深度

列表页按年-月分目录归档（实测 67 页，含 2026 全年各期），更早年份在更后分页。
本单元固定取**最新一期**（发布型数据的正确语义）；如需历史序列，扩 `MAX_LIST_PAGES`
并逐篇解析即可（同构）。
