# moa-hog-price（农业农村部生猪和猪肉价格周报）

农业农村部（MOA）生猪专题 →「市场信息发布」（市场动态）栏目的生猪和猪肉价格周报爬虫单元。
入口函数：`run_moa_hog_price(limit: int = 100, max_pages: int = 2) -> list[dict]`。

每期周报产出 **3 行**（活猪 / 猪肉集贸 / 猪肉批发），各自带监测口径、周次标签与日期区间。

## 端点与取数路径（实测 2026-10-12，UTC+8）

- 列表页：`https://www.moa.gov.cn/ztzl/szcpxx/scxxfb/`（charset **UTF-8**，实测 200）
  - 每页 6 条，站点分页变量 `countPage = 4`，翻页 URL 形如 `index_1.htm` … `index_3.htm`
    （`index_0.htm` 不存在，首页即栏目根路径）。**实测 4 页共 23 篇周报**，
    覆盖 2026-05-11 ～ 2026-10-12（2026年5月第1周 ～ 10月第2周）。
  - 条目结构：`<li><a class="content" href="./202610/t20261012_6488524.htm" title="…">
    <h5>标题</h5><div class="pubTime">发布时间：2026.10.12</div></a></li>`。
  - **文章链接一律从列表页按标题正则（含「生猪」或「猪肉」）发现**，不硬编码任何单篇 URL；
    正文页 URL 由相对路径 `urljoin` 列表页基址得到。
- 正文页：`https://www.moa.gov.cn/ztzl/szcpxx/scxxfb/<yyyymm>/t<yyyymmdd>_<id>.htm`
  - 正文块：`div.TRS_Editor`（位于 `div.detail_content` 内），两段「据农业农村部对…监测」句。
  - 页面头部另有可用元数据：`<meta name="ArticleTitle">`、`<meta name="PubDate" content="2026-10-12 20:18:00">`、
    `<span class="date">发布时间：2026年10月12日</span>`（本单元用列表页发布时间 + href 内嵌日期锚定年份）。

### 一跳说明

`http://www.moa.gov.cn/...` 实测返回 **301 → `https://` 同路径**（`Location` 即 https 同地址）。
本单元直接请求 https，省掉这一跳（与存量单元直连最终地址的做法一致）。

## 两段监测口径（关键坑，绝不合并）

正文同一期内含**两段口径不同**的表述，每行各自标注 `monitor_scope`：

| 品种 | 原文句式 | `monitor_scope` |
|---|---|---|
| `活猪` | 全国活猪价格为 11.07 元/公斤 | `500个县集贸市场和采集点` |
| `猪肉集贸` | 猪肉集贸市场价格为 20.98 元/公斤 | `500个县集贸市场和采集点` |
| `猪肉批发` | 全国猪肉批发市场均价为 15.92 元/公斤 | `200个批发市场` |

实现上：先按句子判定口径（含「200个批发市场」→ 批发；含「500个县集贸市场和采集点」→ 集贸），
再按品种固有口径兜底；**若句子口径与品种固有口径矛盾，该行跳过并记 warning，不猜不混**
（实测 23 期无此情形，纯防御）。

## 文字涨跌幅解析（关键坑）

环比/同比都是文字，不是数字。解析为**带符号数值**：

| 原文 | 输出 |
|---|---|
| `环比跌0.5%` / `环比略跌0.4%` / `环比下降…` | `-0.5` / `-0.4` / 负 |
| `环比涨1.2%` / `环比略涨…` / `环比上升…` | `+1.2` / 正 |
| `环比持平`（无百分号） | `0.0` |
| `同比低15.5%` | `-15.5` |
| `同比高3.5%` | `+3.5` |
| 句中无该表述（如 500 县口径两品种**原文就没有同比**） | `None` |

实测 23 期出现过的写法：`涨`/`跌`/`略跌`/`持平`（环比）、`低`（同比）。正则同时兼容
`略涨/略低/略高/上涨/下跌/下降/上升/升/降/高/持平`，百分号可选。

## 周次与日期区间

- 周次标签在**标题与正文**里（`10月第2周`），日期区间在正文里（`10月5—11日`）。
- `week_label` → `2026年10月第2周`（年份按发布时间锚定）；`date_range` → `2026-10-05~2026-10-11`（ISO）。
- 年份解析（`_resolve_years`）：以发布月为锚，结束月 > 发布月 ⇒ 结束年 = 发布年 − 1（如 1 月初
  发布的 12 月末周）；起始月 > 结束月 ⇒ 跨年（`12月29日—1月4日` ⇒ 起始年 = 结束年 − 1）。
  实测覆盖跨月周（`9月28日—10月4日`、`8月31日—9月6日`），跨年分支为防御性实现。
- 区间分隔符实测为 U+2014 `—`，正则兼容 `—–-~至`。

## 编码

列表页与正文页实测均为 **UTF-8**（`<meta charset="utf-8">`，23 篇全部 utf-8 解码成功）。
`_decode()` 仍按 `utf-8 → gb18030 → utf-8(replace)` 顺序防御性回退，解码异常不致命
（农业农村部站点历史页面存在 GBK 的可能，故不假设单一编码）。

## 容错规则（spec 契约）

- `FetcherSession(impersonate="chrome120", timeout=25, verify=False, retries=1)`：
  **retries=1 = 单次尝试，不重试**；网络异常 / 状态非 200 → 记 warning 后跳过该 URL，
  不连环重试、不做反爬绕过。**实测该站点偶发 25s 无响应**：多次实测中共出现 3 次
  （每次命中不同文章，随机），均按此路径跳过该期、其余期正常返回（如一次全量跑得
  66 行 / 22 期，跳过 1 期；干净一次得 69 行 / 23 期）。属站点侧偶发，非代码缺陷。
- 列表页不可用 → 记 error 并返回空列表（不抛异常给 runner）。
- 单期解析失败（无「监测」句 / 无任何价格行）→ 记 warning 后跳过该期，不阻塞其他期。
- 数值缺失一律记 `None`，**绝不用 0 或占位值填充**；实测 69 行无 None 价格、无 0 价格。
- 行级去重键 `(report_url, item)`。
- `limit` 真实生效：返回行数 ≤ limit（实测 limit=1/2/3/4/7 → 1/2/3/4/7 行）；
  仅当未达 limit 才继续翻页，`max_pages`（默认 2）限制翻页深度。

## 字段清单（12 列）

| 列 | 说明 |
|---|---|
| `week_label` | 周次标签，如 `2026年10月第2周` |
| `date_range` | 监测日期区间，如 `2026-10-05~2026-10-11` |
| `item` | 品种：`活猪` / `猪肉集贸` / `猪肉批发` |
| `price` | 价格（float，元/公斤）；缺失为 None，不填 0 |
| `unit` | 固定 `元/公斤` |
| `mom_pct` | 环比涨跌幅（float，%），跌=-、涨=+、持平=0.0、取不到=None |
| `yoy_pct` | 同比涨跌幅（float，%），低=-、高=+；**500 县口径原文无同比 ⇒ None** |
| `monitor_scope` | 监测口径：`500个县集贸市场和采集点` / `200个批发市场` |
| `report_title` | 报告标题（取自列表页） |
| `report_url` | 正文页 URL |
| `source` | 固定 `moa-hog-price` |
| `scraped_at` | UTC ISO 时间 |

## TLS / 网络口径

`*.moa.gov.cn` 证书为 **CFCA OV**（issuer=China Financial Certification Authority，CN=CFCA OV OCA；
subject CN=`*.moa.gov.cn`，notAfter=2026-12-28），macOS 默认信任库实测校验通过。按仓内既有惯例
统一 **verify=False**（不假设 Linux 容器信任库含 CFCA 根）。国内源：**直连**，未配代理。

## 历史深度

列表页 `countPage=4`，实测可回溯 23 期（2026-05-11 起）。更早的周报可能已归档到列表页
第 5 页之后或旧栏目路径；本单元按 `max_pages` 控制翻页深度（默认 2 页 ≈ 12 期），
需要更深历史时调大该参数即可，采集逻辑无需改动。

## 遗留风险

1. **列表页只保留 4 页**属站点侧分页设置；若站点清理旧页，历史深度会缩短（已取回的行不受影响）。
2. 周次标签年份依赖发布时间的可靠性；若站点出现「发布时间晚于所属周次跨月」的异常排版，
   `_resolve_years` 的发布月锚定可能偏移 —— 实测 23 期无此情形。
3. 品种关键词（活猪/猪肉集贸/猪肉批发）若站点未来改叫法（如「白条猪」），对应行会抽不到并被跳过；
   届时按新表述补 `_ITEMS` 正则即可。
