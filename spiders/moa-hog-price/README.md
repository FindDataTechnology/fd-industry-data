# moa-hog-price（农业农村部生猪和猪肉价格周报 + 生猪产能季度数据）

农业农村部（MOA）生猪专题 →「市场信息发布」（市场动态）栏目的生猪和猪肉价格周报爬虫单元。
入口函数：`run_moa_hog_price(limit: int = 100, max_pages: int = 2) -> list[dict]`。

每期周报产出 **3 行**（活猪 / 猪肉集贸 / 猪肉批发），各自带监测口径、周次标签与日期区间。

同一单元还带第二个函数 `run_moa_hog_capacity(limit: int = 40, window_start: str | None = None, window_end: str | None = None) -> list[dict]`，
取生猪专题「季度数据」的**季度末存栏**（见文末「生猪产能季度数据」一节）。
两者数据源不同、schema 不同，**绝不合并输出**；runner 只加载 `run_moa_hog_price`，
季度命令经该单入口按 `MOA_HOG_COMMAND=capacity` 路由（见该节）。

## 端点与取数路径（实测 2026-10-12，UTC+8）

- 列表页：`https://www.moa.gov.cn/ztzl/szcpxx/scxxfb/`（charset **UTF-8**，实测 200）
  - 每页 6 条，站点分页变量 `countPage = 4`，翻页 URL 形如 `index_1.htm` … `index_3.htm`
    （`index_0.htm` 不存在，首页即栏目根路径）。**实测 4 页共 23 篇周报**，
    覆盖 2026-05-11 ～ 2026-10-12（2026年5月第1周 ～ 10月第2周）。
  - 条目结构：`<li><a class="content" href="./202610/t20261012_6488524.htm" title="…">
    <h5>标题</h5><div class="pubTime">发布时间：2026.10.12</div></a></li>`。
  - **文章链接一律从列表页按标题正则（含「生猪」或「猪肉」）发现**，不硬编码任何单篇 URL；
    正文页 URL 由相对路径 `urljoin` 列表页基址得到。
- 正文页：`https://www.moa.gov.cn/ztzl/szcpxx/scxxfb/<yyyymm>/t<yyyymmdd>_<id>.htm`
  - 正文块：`div.TRS_Editor`（位于 `div.detail_content` 内），两段「据农业农村部对…监测」句。
  - 页面头部另有可用元数据：`<meta name="ArticleTitle">`、`<meta name="PubDate" content="2026-10-12 20:18:00">`、
    `<span class="date">发布时间：2026年10月12日</span>`（本单元用列表页发布时间 + href 内嵌日期锚定年份）。

### 一跳说明

`http://www.moa.gov.cn/...` 实测返回 **301 → `https://` 同路径**（`Location` 即 https 同地址）。
本单元直接请求 https，省掉这一跳（与存量单元直连最终地址的做法一致）。

## 两段监测口径（关键坑，绝不合并）

正文同一期内含**两段口径不同**的表述，每行各自标注 `monitor_scope`：

| 品种 | 原文句式 | `monitor_scope` |
|---|---|---|
| `活猪` | 全国活猪价格为 11.07 元/公斤 | `500个县集贸市场和采集点` |
| `猪肉集贸` | 猪肉集贸市场价格为 20.98 元/公斤 | `500个县集贸市场和采集点` |
| `猪肉批发` | 全国猪肉批发市场均价为 15.92 元/公斤 | `200个批发市场` |

实现上：先按句子判定口径（含「200个批发市场」→ 批发；含「500个县集贸市场和采集点」→ 集贸），
再按品种固有口径兜底；**若句子口径与品种固有口径矛盾，该行跳过并记 warning，不猜不混**
（实测 23 期无此情形，纯防御）。

## 文字涨跌幅解析（关键坑）

环比/同比都是文字，不是数字。解析为**带符号数值**：

| 原文 | 输出 |
|---|---|
| `环比跌0.5%` / `环比略跌0.4%` / `环比下降…` | `-0.5` / `-0.4` / 负 |
| `环比涨1.2%` / `环比略涨…` / `环比上升…` | `+1.2` / 正 |
| `环比持平`（无百分号） | `0.0` |
| `同比低15.5%` | `-15.5` |
| `同比高3.5%` | `+3.5` |
| 句中无该表述（如 500 县口径两品种**原文就没有同比**） | `None` |

实测 23 期出现过的写法：`涨`/`跌`/`略跌`/`持平`（环比）、`低`（同比）。正则同时兼容
`略涨/略低/略高/上涨/下跌/下降/上升/升/降/高/持平`，百分号可选。

## 周次与日期区间

- 周次标签在**标题与正文**里（`10月第2周`），日期区间在正文里（`10月5—11日`）。
- `week_label` → `2026年10月第2周`（年份按发布时间锚定）；`date_range` → `2026-10-05~2026-10-11`（ISO）。
- 年份解析（`_resolve_years`）：以发布月为锚，结束月 > 发布月 ⇒ 结束年 = 发布年 − 1（如 1 月初
  发布的 12 月末周）；起始月 > 结束月 ⇒ 跨年（`12月29日—1月4日` ⇒ 起始年 = 结束年 − 1）。
  实测覆盖跨月周（`9月28日—10月4日`、`8月31日—9月6日`），跨年分支为防御性实现。
- 区间分隔符实测为 U+2014 `—`，正则兼容 `—–-~至`。

## 编码

列表页与正文页实测均为 **UTF-8**（`<meta charset="utf-8">`，23 篇全部 utf-8 解码成功）。
`_decode()` 仍按 `utf-8 → gb18030 → utf-8(replace)` 顺序防御性回退，解码异常不致命
（农业农村部站点历史页面存在 GBK 的可能，故不假设单一编码）。

## 容错规则（spec 契约）

- `FetcherSession(impersonate="chrome120", timeout=25, verify=False, retries=1)`：
  **retries=1 = 单次尝试，不重试**；网络异常 / 状态非 200 → 记 warning 后跳过该 URL，
  不连环重试、不做反爬绕过。**实测该站点偶发 25s 无响应**：多次实测中共出现 3 次
  （每次命中不同文章，随机），均按此路径跳过该期、其余期正常返回（如一次全量跑得
  66 行 / 22 期，跳过 1 期；干净一次得 69 行 / 23 期）。属站点侧偶发，非代码缺陷。
- 列表页不可用 → 记 error 并返回空列表（不抛异常给 runner）。
- 单期解析失败（无「监测」句 / 无任何价格行）→ 记 warning 后跳过该期，不阻塞其他期。
- 数值缺失一律记 `None`，**绝不用 0 或占位值填充**；实测 69 行无 None 价格、无 0 价格。
- 行级去重键 `(report_url, item)`。
- `limit` 真实生效：返回行数 ≤ limit（实测 limit=1/2/3/4/7 → 1/2/3/4/7 行）；
  仅当未达 limit 才继续翻页，`max_pages`（默认 2）限制翻页深度。

## 生猪产能季度数据（`run_moa_hog_capacity`）

### 端点与跳转链（实测 2026-11-08，UTC+8）

- 入口：`https://www.moa.gov.cn/ztzl/szcpxx/jdsj/`（生猪专题 →「季度数据」）
  - 入口与年份目录都是 **meta-refresh 跳转壳**，必须逐跳跟到月份页：
    `/jdsj/` → `/jdsj/<YYYY>/` → `/jdsj/<YYYY>/<YYYYMM>/`
    （实测 `refresh: 0;url=./2026/` → `0;url=./202609/`；脚本 `window.location` 为兜底）。
  - 月份页另带「选择时间」导航（`li[objurl]`）：年份 2021~2026、当年已发布月份。
    年份目录 `/jdsj/<YYYY>/` 跳到该年最末月，从该月导航可拿到该年全部已发布月份。
- 数据在月份页**静态 HTML 表格** `table.data_table`（生产 / 价格 / 进出口三张），无需 JS；
  本函数只取「生产」表的季度末存栏行。
- **发布频次为季度**（页面原文：每年 1 月 20 日、4 月 20 日、7 月 20 日、10 月 20 日）。
  实测 `202608/` 页**无任何存栏行**（只有屠宰量与价格），`202609/` 页才有
  `2026年3季度末能繁母猪存栏`/`2026年3季度末生猪存栏` ⇒ **月度产能数值不存在**，
  本函数只产出季频行，不插值、不推算、不标月频。
- 只走季度末月份（03/06/09/12），非季末页不请求。

### 实测样例行（`202609/`）

| 指标 | 数值 | 环比 | 同比 |
|---|---|---|---|
| 2026年3季度末能繁母猪存栏（万头） | 3602（相当于调控目标的96.0%） | -4.7% | -10.7% |
| 2026年3季度末生猪存栏（万头） | 42533 | 0.1% | -2.6% |

### 必须处理的坑

1. **PC/移动双份表**：同一产能行在 `table.data_table`（PC，5 个 td）与
   `table.data_table_mobile`（移动，标签/值两列）各出现一次，全页（含备注文字）实测
   出现 5 次 ⇒ 按 `(quarter, item)` **去重**，PC 表优先。
2. **数值单元格内嵌 `<br><span>`**：如 `3602<br><span>（相当于调控目标的96.0%）</span>`。
   先 `text_content()` 剥成纯文本，再取**首个数字**为 `value`；括注单独用正则取
   `target_ratio_pct`（兼容「相当于调控目标的96.0%」与 2025 年前的
   「相当于正常保有量的101.6%，产能正常，处于绿色区域」）。
3. **`—` 表示不适用** ⇒ 记 `None`，**不写 0**（实测生猪出栏/累计屠宰量等行的环比为 `—`；
   本函数的两行 2021Q4~2026Q3 实测量值均有值）。
4. **xlsx 附件 href 落在次月目录**（如 202609 页的 `./202610/*.xlsx`，相对路径易 404）
   ⇒ 本函数**不依赖附件**，只解析页面表格。
5. **季度数字有两种写法**：多数页为 `2026年3季度末`，实测 `2023年三季度末`（中文数字）
   同时存在 ⇒ 正则兼容 `1-4` 与 `一/二/三/四`。
6. 导航可能列**死链**：2021 年导航列了 `202106`/`202109`，实测两页 404（`202103` 起
   更早月份也不存在）⇒ 取数失败按契约跳过，不重试；历史实际起点为 **2021Q4**。

### 季频与入口路由

- **granularity = 季度**：manifest `frequency: quarterly`，描述写明「季频，1/4/7/10 月
  20 日发布，无月度数值」；`period_end` 恒为季末日，`quarter` 恒为 `YYYYQn`。
- runner 只加载 `run_<slug>`（即 `run_moa_hog_price`），没有第二个入口。新增命令经该单入口
  可达：设置 `MOA_HOG_COMMAND=capacity` 时 `run_moa_hog_price` 转调
  `run_moa_hog_capacity(limit=…)`；**不设置时价格路径行为与输出完全不变**（季度行不会混入
  价格输出）。`window_start`/`window_end` 也可用 `FD_WINDOW_START`/`FD_WINDOW_END` 注入。

### 真实取数证据

- 取数时间 **2026-11-08 00:55（UTC+8）**，`python3`（scrapling + lxml）实测：
  `run_moa_hog_capacity(limit=40)` → **40 行 / 20 个季度 / 2021Q4 ~ 2026Q3**，耗时 ~15s。
  `value` 无 None、无 0；`qoq_pct`/`yoy_pct` 无 None；`target_ratio_pct` 25 个 None
  （20 个 `hog_inventory` 行 + 5 个原文无括注的能繁母猪季度）。
- 最新季度：2026Q3 能繁母猪 `3602`（target 96.0，qoq −4.7，yoy −10.7）、

### 该函数特有风险

1. 站点偶发 25s 超时（与价格路径相同）：`retries=1` 单次尝试，跳过该月页，其余季度照常返回；
   一次失败即少 2 行。
2. 若未来月份页改用新模板（表格 class 变更），解析会得到 0 行并被跳过；届时按新结构补
   `table.data_table` / `table.data_table_mobile` 选择器即可。
3. 季度数字/括注措辞若再变（如「第3季度」「能繁母猪存栏量」），需同步扩展
   `_QUARTER_LABEL_RE` / `_TARGET_RATIO_RE`。

## 遗留风险

1. **列表页只保留 4 页**属站点侧分页设置；若站点清理旧页，历史深度会缩短（已取回的行不受影响）。
2. 周次标签年份依赖发布时间的可靠性；若站点出现「发布时间晚于所属周次跨月」的异常排版，
   `_resolve_years` 的发布月锚定可能偏移 —— 实测 23 期无此情形。
3. 品种关键词（活猪/猪肉集贸/猪肉批发）若站点未来改叫法（如「白条猪」），对应行会抽不到并被跳过；
   届时按新表述补 `_ITEMS` 正则即可。
