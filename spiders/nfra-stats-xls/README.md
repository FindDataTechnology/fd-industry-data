# nfra-stats-xls —— 金融监管总局 银行业监管统计表（Excel 附件通道）

新源接入档案（批次六·银行业，change `add-banking-industry-sources` 任务 1.1）。

## 为什么是附件通道（设计决策 D1）

`SelectByDocId` 的 `docClob` 是 Word-HTML 导出，正文**只有 1 个 `<img>`、0 个 `<table>`**
（2026-11-07 抽样 10/10 全为此形态），PDF 也无文本层。唯一机器可读形态是
`attachmentInfoVOList` 里的 **BIFF8 `.xls`**（无鉴权，裸请求 200/206）。

2026-10-13「NFRA 扫描件需 OCR 暂不接」裁决**对象是「需 OCR 才能结构化」的源**；
附件通道无需 OCR，不触及裁决原文。若附件通道日后断供，OCR 三件套（MinerU token +
golden 锚 + 对位失败不出数）仍是唯一解锁路径——原裁决保留效力。

## 数据表面

| 用途 | 端点 | 方法 | 说明 |
|---|---|---|---|
| 列表 | `/cbircweb/DocInfo/SelectDocByItemIdAndChild?itemId=954&pageIndex=N&pageSize=20` | GET | `pageSize` 传参被无视、**恒 20/页**；954 栏目 1,386 条 |
| 详情 | `/cbircweb/DocInfo/SelectByDocId?docId=<id>` | GET | 必带双头 `Referer: https://www.nfra.gov.cn/` + `X-Requested-With: XMLHttpRequest` |
| 附件 | `https://www.nfra.gov.cn/chinese/docfile/<年>/<uuid>.xls` | GET | BIFF8；`Content-Type` 不可信，靠 `tabular.detect` 按魔数判 |

**json 解析须 `strict=False`**：`docClob` 内嵌 Word-HTML，含未转义控制字符，默认解析会炸。

## 表头两种布局（parser 兼容，二者实测并存）

```
2026 期：  时间 | 2026年                    ← 年
           项目 | 一季度 | 二季度 | …        ← 周期在「项目」行
2025 期：  时间 | 一季度 | 二季度 | …        ← 周期在「时间」行
           项目 |                            ← 项目行空置
```

解析器按「第一个出现周期标签的行」定表头，两种布局都命中；项目行若无数值自然跳过。

## 比率口径（重要）

源表 `%` 单元格全部是 **Excel 百分数格式的小数形**，实测：

| 指标 | 单元格原值 | 发布口径 |
|---|---|---|
| 不良贷款率 | 0.01518 | 1.518% |
| 资本充足率 | 0.15256 | 15.256% |
| 拨备覆盖率 | 2.03137 | 203.137% |
| 存贷比（人民币） | 0.79744 | 79.744% |

故凡指标名含 **率 / 占比 / 比 / 比例** 且单位行含 `%` 者，值 ×100 并按 `%` 落库；
其余按 `亿元`。这是「按发布口径归一」，非数值猜测——16 个比率行全量抽样均满足小数形。

## 原位更新纪律（spec 专条）

月度《总资产、总负债（月度）》**年度一个 docId 原位更新**（2026 年 = `1265692`，
`publishDate` 随最新月刷新、**附件 uuid 月度轮换**）。本单元**每次运行都重查
`SelectByDocId`** 取最新直链，不缓存 uuid——附件轮换后仍能取到最新月度数据。

## 坑位（侦察簿路 1，逐条落实位置）

1. `pageSize` 恒 20（`discover()` 按 20 规划翻页，最多 8 页 = 160 文档 ≈ 2024–2026）。
2. `docClob` 控制字符 → `json.loads(strict=False)`。
3. 月度表同 docId 原位更新 → 每轮重查详情（见上）。
4. 标题口径漂移（2024/25 带「（季度）」后缀）→ 按**关键词组**匹配，不按整名相等。
5. `xls` = BIFF8 → `fd_industry_data.tabular.read_grid`（xlrd 路线），禁止内联手写。
6. 955 图表栏目文档数 0（SPA 404）→ 本单元不涉及。

## 失败策略

单文档/单表解析失败 → stderr 留痕并继续（实测 2025 年某表曾因表头布局差异失败，
已修为双布局兼容）；全部失败 → `RuntimeError`；空格不出行（绝不用 0 填充）；
`limit` 真实生效。默认 `limit=300`，生产按需放大（整年五族约 750 行、三年约 1,600 行）。
