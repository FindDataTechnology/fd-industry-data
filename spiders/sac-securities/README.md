# sac-securities —— 中国证券业协会（SAC）证券公司经营数据

批次落地单元（由侦察骨架 manifest 落地为正式单元）。**免 key、免鉴权、直连可达**
（无需代理出口，manifest 不声明 `egress_secret`）。

## 0. 与侦察骨架 manifest 的关系

仓库 `manifests/` 下有三个 SAC 相关的**侦察骨架**（旧侦察格式，方向性记录，勿改）：

| 骨架 | 方向 | 与本单元的关系 |
|---|---|---|
| `manifests/sac-securities.yaml` | 「证券交易」get_trading_volume | 落地时以本目录为准：实现的是同一来源（sac.net.cn）的**证券公司经营数据**方向（行业汇总营收/利润/资产），非逐日交易量 |
| `manifests/sac-securities-trading.yaml` | 「证券交易数据」get_trading_volume | 同上；SAC 官网无逐日交易量公开统计，该方向未落地，骨架保留未删 |
| `manifests/securities.yaml` | 「证券业协会行业数据」get_data（source_url 写的是 amac.org.cn，实为基金业协会域名，侦察误记） | 本单元即其「行业数据」方向的正式落地；骨架保留未删 |

**落地 = 本目录（`spiders/sac-securities/`）为唯一权威**；三个骨架仅作侦察史留档。

## 3. 口径约定

- **stat_period = `YYYY-Qn`（累计口径）**：上游数值均为年初至报告期末的累计数。
  标题映射：`年度`→Q4、`上半年度`→Q2、`前三季度`/`三季度`→Q3、`一季度`→Q1。
  例如「2018年三季度经营数据」正文为「当期实现营业收入1,893.31亿元」，介于 2018H1
  （约 1,306 亿）与 2018 年度（约 2,663 亿）之间，确证为 1-9 月累计。
- **金额统一折算为亿元**（unit 常量 `"亿元"`）：解析时捕获数字后的计量单位，
  `万亿元` ×10000。不硬编码单位——上游单位随期漂移（见坑位）。
- **indicator 剥离括号限定语**：官方全名随期微调（2019「代理买卖证券业务净收入
  （含席位租赁）」vs 2025「（含交易单元席位租赁）」），剥离后跨期可 join。
  官方全名码表：

  | 本单元 indicator | 官方全名（近年） |
  |---|---|
  | 营业收入 | 营业收入 |
  | 净利润 | 净利润 |
  | 代理买卖证券业务净收入 | 代理买卖证券业务净收入（含交易单元席位租赁） |
  | 证券承销与保荐业务净收入 | 证券承销与保荐业务净收入 |
  | 财务顾问业务净收入 | 财务顾问业务净收入 |
  | 投资咨询业务净收入 | 投资咨询业务净收入 |
  | 资产管理业务净收入 | 资产管理业务净收入 |
  | 利息净收入 | 利息净收入 |
  | 证券投资收益 | 证券投资收益（含公允价值变动） |
  | 总资产 / 净资产 / 净资本 | 总资产 / 净资产 / 净资本（截至报告期末） |
  | 客户交易结算资金余额 | 客户交易结算资金余额（含信用交易资金） |
  | 托管证券市值 | 托管证券市值（仅早期文章出现） |
  | 受托管理资金本金总额 | 受托管理资金本金总额 |

- **company_scope 常量 `行业汇总`**：数值为当期全部证券公司合计（家数 131..150 随期
  变化，正文可变、不作字段透出）。

## 5. 坑位

- **brief 线索路径已死**：`/hgsjbgz/` 404。现入口是「信息公开 > 行业数据 >
  证券公司经营数据」（`/xxgk/hysj/jjsj/`），从官网首页导航可达。
- **无 JSON、无表格、无附件**：数据只在散文里。别试图找接口或解析表——正文
  `<table>` 出现 0 次，附件区为空。
- **计量单位随期漂移**：资产负债类指标早年用「亿元」（2018Q3 客户交易结算资金
  余额 9,743.81 亿元）、近年用「万亿元」（2025 年度 3.24 万亿元）。必须捕获数字
  后的单位再归一，不可按指标名硬编码单位。
- **括号限定语全角/半角混用、措辞随期变**：`（含信用交易资金）`/`(含信用交易资金)`、
  `（含席位租赁）`/`（含交易单元席位租赁）`——指标名统一剥离括号后透出。
- **误配陷阱**：正文「120家公司实现盈利」「累计超过5.2亿元」（2020Q1 抗疫捐助
  叙事）等含数字句子不得进入金额——所有模式锚定完整指标短语（如「实现净利润」
  而非裸「净利润」）。
- **「当期实现」措辞**：2018 年文章用「当期实现营业收入」，实为年初至报告期末
  累计（已用 H1/年度数值交叉验证），口径与其他期一致。
- **披露节奏不均匀**：早年季度、近年半年度；`stat_period` 只有实际披露的期，
  缺期不补齐（行粒度=每期每指标，非规则时间轴）。
- **频次敏感**：单次运行 = 列表页 1 次 + 为满足 `limit` 所需的文章页（上限
  `MAX_ARTICLES=8` 篇），不重试、不批量爬列表第 2 页。
- **仅常规 UA**：免鉴权站点，不做指纹伪装与频次对抗，遇风控升级按协议转人工。
- **失败即红**：HTTP 错误 / 列表 0 文章 / 单篇 0 指标行 / 总 0 行 → 抛
  `RuntimeError`，不静默回空。

## 6. golden 断言口径（跨期稳定）

`golden/001-sac-securities.json` 用 `{"limit": 20}` 重放（实际返回最近两期约 20 行），
`rows_contains` 只锚结构常量 `source=sac-securities`；`min_rows>=1`。
**绝不锚**任何 `value` 金额（上游可对当期数回修）与期次；`scraped_at` /
`upstream_updated` 进 `whitelist_fields`。
