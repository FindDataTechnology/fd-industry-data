## 坑位（侦察簿路 3，逐条落实位置）

1. **脚注是 `<sup>` 元素**：`普惠小微贷款<sup>1</sup>余额38.50万亿元`。`zoom_text()`
   先删 `<sup>…</sup>` 再剥标签（`spider.py` 首行处理）。若改成「删所有孤立数字」
   会误伤 `500万元`/`2026年`——故必须按元素删。
2. **URL 时间戳失真** → 发布日期只取 `<meta name="PubDate">`。
3. **目录是混合新闻流** → 只按标题 `贷款投向统计报告` 匹配，不按位次/URL 形态。
4. **标题口径漂移**（2024/25 期带「（季度）」后缀等）→ 期次解析覆盖 Q1–Q4/H1/年度，
   同标题多次出现按期次去重。
5. 央行 LPR 栏目 404 与本单元无关（LPR 走 `chinamoney-lpr`）。

## data_period 选择理由

`irregular`：数据是**季度**发布，而枚举只有 day/month/year/irregular。
`month` 容忍窗 35 天会在两个季度窗之间产生假超期告警；`year`(370 天) 过宽失去意义。
故按 irregular 登记（超期由 `gap_in_series` 断档检测兜底），排期仍按季度窗
`12 15 15 1,4,7,10 *` 巡检。

## 失败策略

- 单篇失败/期次不可解析/正文抽空 → 跳过并 `stderr` 留痕，不阻塞其它期次；
- 全部失败 → `RuntimeError`（失败即红，绝不静默回空表）；
- 抽不到的指标不出行（绝不用 0 占位）；`limit` 真实生效。

依赖：仅标准库 `urllib/json/re/datetime`。
