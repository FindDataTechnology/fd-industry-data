# nfra-penalty —— 金融监管总局 行政处罚公示（三叶子栏目）

新源接入档案（批次六·银行业，change `add-banking-industry-sources` 任务 1.2）。

## 为什么只解析 docClob HTML 表

侦察簿路 2 记「双格式并存：旧文档 docClob=Word 导出 HTML，NFRA 时期=批量 PDF 表」。
本波实测把这条口径**收窄**了：2026-11-07 抽样三个叶子栏目共 **36 篇**（每叶 12 篇），
**36/36 的 docClob 都含且仅含 1 个 `<table>`**，`attachmentInfoVOList` 全为 0，
`pdfFileUrl` 恒存在——PDF 是**同一张表的 WPS 渲染件**，不是独立形态。

PDF 不做结构化解析的实测依据：

| 证据 | 结果 |
|---|---|
| `pdftotext -layout` | 列边界随单元格文字宽度塌陷（`序号` 与 `当事人名称` 交错、`作出决定机关` 折成三行） |
| `pdftotext -bbox-layout` + 块坐标聚类 | 5 列并成 4 列、相邻行串位（1277747 原型实测） |
| `pdftotext -bbox-layout` 本身 | 1277175 直接 **SIGABRT**（poppler 退出码 6） |

故本单元**只走 HTML 通道**；若日后正文退化为纯图片，属 2026-10-13「需 OCR 才接」
裁决范围，按该裁决重开（不自行扩大范围）。

## 数据表面

| 用途 | 端点 | 方法 | 说明 |
|---|---|---|---|
| 列表 | `/cbircweb/DocInfo/SelectDocByItemIdAndChild?itemId=<leaf>&pageIndex=N&pageSize=20` | GET | 叶子 4113 总局 / 4114 监管局 / 4115 监管分局；`pageSize` 恒 20 |
| 详情 | `/cbircweb/DocInfo/SelectByDocId?docId=<id>` | GET | 必带双头；`docClob` = Word-HTML 表 |
| 文档 | `https://www.nfra.gov.cn/chinese/OFFICE/PDF/<docId>.pdf` | GET | 同表 PDF（仅作 `doc_url` 溯源，不解析） |

**双头**：`Referer: https://www.nfra.gov.cn/` + `X-Requested-With: XMLHttpRequest`，缺一即 403/空体。
**`json.loads(strict=False)`**：`docClob` 内嵌 Word-HTML 含未转义控制字符。
**限流**：突发时返回 **HTTP 200 但 `rptCode != 200`**（另实测偶发裸 HTTP 403），
两种都按 ≥90s 退避重试一次（`BACKOFF_SECONDS`），仍未恢复则该叶/页放弃并留痕。

## 为什么只打三个叶子（不打 931）

侦察簿：931 聚合栏目排序异常（p1 从 2018-12 升序）且 `total`(144,820) ≠ 叶子之和(150,501)；
支局级 4292 全局仅 2 条不值得建通道。**监控只打 4113/4114/4115**。
服务端检索（searchkey / publishDateBegin/End）实测是**空操作**（total 不变），
故所有过滤只能在本地做——本单元不做本地过滤，按列表 newest-first 原样落库。

## 两种表格布局（实测并存，按表头映射而非列序）

```
5 列：序号 | 当事人名称 | 主要违法违规行为 | 行政处罚内容 | 作出决定机关
6 列：序号 | 当事人名称 | 行政处罚决定书文号 | 主要违法违规行为 | 行政处罚内容 | 作出决定机关
```

`_locate_header()` 在前 6 行里找同时命中「当事人/处罚内容/机关」的行，按别名建列映射；
两种布局共用同一套取值逻辑，**不按列序号写死**。6 列布局只在部分监管局/分局文档出现。

`penalty_no` 取列值；该布局缺席时回落标题括注（如「…公开表（冀金罚决字〔2026〕68号）」）；
总局批量公示列表两者都无 → 空串（不是缺陷，是该栏目的发布形态）。

## 金额口径（amount，万元）

行粒度 = 表内一行 = 一个（组）当事人。`amount` = 该行**处罚内容里所有罚款之和**：

| 原文片段 | 取值 |
|---|---|
| `对兴业银行股份有限公司罚款695万元` | 695.0 |
| `对民生人寿…罚款160万元，对赵琦、吴志军、孔令丰警告并罚款合计24万元` | 184.0 |
| `合计处以95万元罚款` | 95.0（金额前置，靠后窗 3 字「万元罚款」命中） |
| `对机构罚款40万元。对游明义…警告并罚款共计26万元` | 66.0 |
| `没收违法所得10万元并处罚款20万元` | 20.0（没收不计入） |
| `对仇征给予禁止从事银行业工作5年的行政处罚` | `null`（无罚款，**绝不填 0**） |

## 叶子轮转（防单叶吃满预算）

总局批量公示列表一篇可有 50+ 行，顺序取会把 `limit` 全吃掉，**分局形态（唯一普遍带文号的）
永远轮不到**。故 `run_nfra_penalty` 先取三叶列表，再**按文档轮转**取详情。
首爬每叶 ≤3 页（60 篇 ≈ 最近 1–2 个月全量）。

## 实测取数证据（2026-11-07 首爬）

`limit=150` → **150 行 / 57 篇 / 三叶齐 / 耗时 ~80s（含一次 90s 403 退避）**：

```
leaf : general_bureau 64 | bureau 50 | branch 36
level: 总局 90 | 局 41 | 分局 19
带文号 25 行 | 无罚款（仅警告/禁业）19 行
兴业银行股份有限公司 695 万 / 中国光大银行股份有限公司 180 万 / 浦银理财 918.22 万
甘金监行处〔2026〕433号（交通银行兰州新区支行 35 万）/ 豫金罚决字〔2026〕89号（禁业 10 年）
```

## 坑位（侦察簿路 2，逐条落实位置）

1. 双头缺失 → 403/空体 → `HEADERS` 常量。
2. `rptCode != 200` 假 200（CDN 缓存期仍活，误导排障）→ `_api_guarded`。
3. `pageSize` 传参被无视 → `PAGE_SIZE = 20` 固定，翻页按 20 规划。
4. 服务端检索空操作 → 不做服务端过滤（本地过滤留给下游）。
5. 931 聚合坏 + 支局 4292 稀疏 → `LEAVES` 只登记三叶。
6. 同一文档一表多案 → 行粒度按表行，`doc_id` 允许重复。

## 失败策略

单文档失败 → stderr 留痕并继续；单叶列表失败 → 其余两叶继续；
全空 → `RuntimeError`；`amount` 无罚款为 `null` 不填 0；`limit` 真实生效。
