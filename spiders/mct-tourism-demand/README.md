## 字段口径

| 列 | 来源 | 口径 |
|---|---|---|
| `period` | 标题正则 | `YYYY` / `YYYYH1` / `YYYYQ1-Q3` / `YYYYQn`；**期次看标题，不看发布日**（发布滞后 2–5 个月） |
| `period_kind` | 标题 | `fy` / `ytd_h1` / `ytd_9m` / `quarter` —— **累计与单季永不共用一个 kind** |
| `scope` | 句内主语 | 全国 / 城镇 / 农村；公报的入境类用 外国 / 港澳台 / 内地 |
| `indicator` | 锚定短语 | `domestic_trips` `domestic_spending` `inbound_trips` `foreign_inbound_trips` `hkmotw_inbound_trips` `outbound_trips` `travel_agencies` `star_hotels` `star_hotel_revenue` `star_hotel_adr` `star_hotel_occ` `a_level_scenic` `scenic_visits` `scenic_revenue` |
| `value` | 数词 | float，**保留上游单位原样，不做量纲换算、不四舍五入、不插值** |
| `unit` | 单位词 | 亿人次 / 万亿元 / 万人次 / 家 / 亿元 / 元/间夜 / % / 个 |
| `yoy_pct` | 同句「同比增长/下降 x%」 | 下降取负；未公布留空 |
| `delta` / `delta_unit` | 同句「比上年增加/减少 x 单位」 | **单位必须与指标同族**，否则不给 |
| `source_kind` | 文档类型 | `dispatch` / `bulletin` |
| `indicator_note` | 上游原话片段 | 审计用 |
| `report_title` / `doc_url` | 标题 / 详情页 | 行级可回溯 |
| `source` / `scraped_at` | 常量 / 本地 | `mct-tourism-demand` / UTC ISO8601 |

## 坑位与容错（侦察 + 实跑逐条落实）

1. **不是表，是句子**：抽取写死「锚定短语 + 数词 + 单位」，任一 dispatch 稿解析不出
   `国内居民出游人次` 即 `UnmappedPhrase` → 整次运行 `RuntimeError`（换措辞必须炸）。
2. **句界必须截断**（本单元最危险的两个串味，实测抓出来的）：
   - 不截断会把 2024 公报里下一句的 `同比增长14.8%` 挂到「旅行社 64616 家」上；
   - 不截断会把「出游总花费比上年增加 0.55 万亿元」当成「农村出游人次的增量」。
   → `_tail()` 只在本句内（`。` / `；`）取值，且增量单位须与指标同族（`DELTA_UNIT_FAMILY`）。
3. **累计 vs 单季两个粒度并存**：上半年稿额外给「分季度看，一季度…19.01…；二季度…15.62…」，
   于是 2026Q1 同时在 Q1 稿与 H1 稿里出现。`_merge()` 按
   `(期间, 粒度, 口径, 指标)` 去重：同值留痕 `同值复现`，异值留痕 `口径冲突` 且**两行都留**。
4. **城镇 / 农村不是补充说明，是可比两档**：三档（全国/城镇/农村）都入行，不许只取总数。
5. **公报的星级饭店口径 ≠ 季报口径**：公报是**统计直报系统**汇总（2025 全年营收 1448.0 亿元），
   季报是「全国星级饭店经营情况统计表」（2024 四期营收加总明显高于公报 2024 的 1557.3 亿元）。
   故公报行带 `source_kind=bulletin`，**不与季报同行合并、不互相补齐**。
6. **正文含大量内联 CSS**：`<style>` / `<script>` 整块剥掉后再剥标签，否则样式文本污染正则。
7. **数字被标签/换行切开**：`49.98<!-- -->亿`、`同比增长1\n8.0%` —— 归一化时压掉全部空白
   （含全角空格 / `&nbsp;`），所以锚定短语必须写成无空格形式。
8. **更早年份公报措辞不同**（`国内旅游人数`），`BULLETIN_MIN_YEAR=2024` 之前整份跳过并留痕。

## 历史深度

栏目静态分页共 40 页；`pages=3` 覆盖栏目第 1–3 页（2024-09-02 以后全部季度稿与 2024/2025 两份公报）。
更早的公报可回溯，但口径措辞不同，默认跳过；需要时改 `BULLETIN_MIN_YEAR` 并补锚定短语。
