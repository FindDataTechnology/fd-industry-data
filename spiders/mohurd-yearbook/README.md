# mohurd-yearbook — 住建部城市建设与城乡建设统计年鉴

住房和城乡建设部「统计信息」栏目发布的两个年鉴附件，取其中的**全国历年时间序列**：

| 附件 | 格式 | 取什么 |
|---|---|---|
| `YYYY年城市建设统计年鉴.xls` | OLE2/BIFF `.xls`，47 表 | 表名纯数字者（`1`..`11`）= **全国历年**序列，1981/1978–2025 |
| `YYYY年城乡建设统计年鉴.zip` | ZIP 内 90 个 `.xls` | `03村镇部分/3-1-*` = **建制镇/乡/村庄历年**序列（普惠金融相关） |

- 栏目：<https://www.mohurd.gov.cn/gongkai/fdzdgknr/sjfb/index.html>
- 排期：`52 6 12 1 *`（每年 1 月 12 日；**年刊**，年频数据不每日抓）
- 入口：`run_mohurd_yearbook(limit=200, dataset="all")`，`dataset` ∈ `national` / `rural` / `all`
- 依赖：标准库 + **平台共享层 `fd_industry_data.tabular`**（本单元是该层的首个消费者）

## 为什么这个单元存在

批次五把住建部年鉴列为障碍（"内层 BIFF `.xls`，解析须 `xlrd`，属运行时依赖决策"）。
用户 2026-10-13 授权装依赖但要求**做成通用能力**——于是先建了
`fd_industry_data.tabular`（格式探测 / xlsx / xls / html / zip / 表头探测），
本单元作为首个真实消费者验证该层，同时把这条留痕从「障碍」转为「已交付」。

**本单元不含任何手写解析**：探测、读表、多表选择、ZIP 中文名还原全部走共享层。

- 合并年鉴 2,264,576 B，magic `d0cf11e0`（OLE2）→ `detect` 判为 `xls`；47 表

## 坑位（全部实测）

1. **表头高度不固定**（实测 3–5 行；村镇表因合并单元格可达 13 行）。
   本单元**不靠固定行号**：按「首列为 4 位年份」定位数据起点，表头取数据起点
   之前**紧邻的连续非空块**，列名由该块各列文本拼接。
2. **中英同格**：一个单元格里既有中文名又有英文翻译与英文单位补注，形如
   `建 制 镇\n统计个数\n(万个)\nNumber of\nTowns\n\n(10000 units)`。
   不剥离会让指标名变成中英混杂、单位取成 `10000 units`。共享层
   `strip_latin_runs` 处理（**保留中文单位括号**，只删纯拉丁括号补注）。
3. **中文对齐空格**：`供    水            普及率` 里的字间空格是排版填充，
   不是语义空格。共享层 `squash_cjk` 只删 CJK 之间的空白，保留中英之间的
   （`年份 Year`）。
4. **两个数据集会互相挤占 `limit`**：顺序拼接时 `national` 会吃光额度，
   使 `all` 模式下 `rural` 拿不到行（实测 limit=400 时 rural 为 0）。
   故按**轮转交织**截断——任一小 limit 下两个数据集都有代表（实测 limit=6 → 3+3）。
5. **年份列非年份的行**是注记/汇总行，跳过；**空格不产行**（不填 0、不插值）。
6. **数值原样保留为字符串**，不做数值转换（与共享层约定一致）；需要数值的
   下游自行转换。

## 口径说明

- 表名 `1-1`/`1-1-1` 等是**当年按省/按城市分列**，与本单元的「全国历年」不同口径，
  本单元**不取**（只取纯数字表名）。
- `table_title` 保留年鉴原标题（含覆盖年份范围），供下游核对口径。
