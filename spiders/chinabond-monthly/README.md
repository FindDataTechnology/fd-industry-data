# chinabond-monthly —— 中债登 债券市场统计分析月报（8 表）

新源接入档案（批次六·银行业，change `add-banking-industry-sources` 任务 4.2）。

## 端点（从栏目页 JS 实读）

栏目页 `https://www.chinabond.com.cn/zzsj/zzsj_tjsj/tjsj_tjyb/` 的 JS 两步：

```js
// 1) 某年月的月报目录（8 张表）
$.ajax({ url: "/cbiw/GetMonthReport/queryContent", type: "POST",
         data: { language: language, reportFlag: reportFlag, sMonth: s_Month, sYear: s_Year } })

// 2) 按表号取文件
$.ajax({ url: "/cbiw/GetMonthReport/GetDataByte", type: "POST",
         data: { sBbly: tjTime, sCode: sCode, sWjlx: downType } })   // downType=3 自 201509 起
```

实测（2026-11-08）：

| 请求 | 结果 |
|---|---|
| `queryContent sYear=2026 sMonth=10 reportFlag=T` | `[]`（10 月报未发） |
| `queryContent sYear=2026 sMonth=09 reportFlag=T` | 8 条记录（`bbbh` 01…08 + `bbmc` 表名 + `ywbbnr` base64 PDF） |
| `GetDataByte sBbly=202609 sCode=01..08 sWjlx=3` | 每表 5.0–5.7 KB `PK..` OOXML xlsx |

## 三个硬坑

1. **`reportFlag` 必须取 `T`**——这是栏目页隐藏表单里的值。取 `0`（默认本年月）、
   `1`、`2` 实测一律返回 `[]`；取 `T` 才出 8 表。侦察簿未记此点，本单元从页面
   JS 的 `reportFlag` 变量回溯到隐藏域实读确认。
2. **未发布月份返回 `[]` 而非 404**，与"该月无数据"无法从状态码区分，只能靠
   空数组判定——所以本单元把 `[]` 当"未发布"继续往回探测，而不是当错误重试。
3. **`sCode` 直接用 `bbbh`**（`01`…`08`），不存在侦察簿路 5 记的"页码与 sCode
   差一位"问题（那属另一个下载页 `GetDataByte` 的另一组调用）。本单元不碰页码。

`queryContent` 里的 `ywbbnr` 是**同一张表的 base64 PDF**（`JVBERi0` = `%PDF-1.4`），
`GetDataByte` 的 `sWjlx=3` 才是 xlsx。本单元只走 xlsx 通道：PDF 里的表格用
`pdftotext -layout` 会串列，而 xlsx 是原生的行列结构，走共享层 `tabular` 即可。

## 表骨架（8 表统一）

```
row0  表名（"4.债券托管情况"）
row1  空
row2  统计年月：202609
row3  单位：只，亿元
row4  表头（首列空；07/08 为两行表头：交易方式 + 本月/本年累计）
row5+ 合计 / 一、银行间债券市场 / 1.商业银行 / … 数据行
```

**01 表没有「合计」行**——首行直接是 `1.债券发行量`（它是按指标组织的总览表，
不是按券种）。因此数据起始行的判定是 `合计` / `一、` / `N.` 三者任一命中，
只认 `合计` 会让 01 表整表丢失（首轮实测即如此：27 行 → 解析失败）。
01 表还带 3 行非亿元行：`4.债券托管量`（亿元）、`5.投资者数量`（个）、
`附：美元债托管量（美元）`（美元）。

两行表头的列标签用 `·` 拼接（前向填充组头），例如 07 表得
`现券交易·本月`、`现券交易·本年累计`、`质押式回购·本月`……

## 单位规则（显式表，不做推断）

`单位：` 行是**表级**声明，但这三张表的单位按行或按列分叉，故用显式规则表
（`TABLE_UNITS`，README 与代码同源）：

| 表 | 单位行原文 | 解析规则 |
|---|---|---|
| 01 债券业务总览 | `亿元，个` | 行含「数量」→ `个`；行含「美元」→ `美元`；其余 → `亿元` |
| 04 债券托管情况 | `只，亿元` | 指标含「只数」→ `只`；指标含「面额」→ `亿元` |
| 其余 6 表 | `亿元` | 一律 `亿元` |

01 表两个 token（亿元、个）**不是按列对应**（两个指标列都是本月/本年累计），
而是按**行**对应——所以不能用"token 数 == 指标列数"的通用对齐规则，那样会把
`本年累计` 列错标成 `个`。

## 为什么 golden 钉 `period`

tasks.md 4.2 要求「golden 锚=2026-09 商业银行持债合计（886,790.81 亿等）」。
若按默认口径（取最新已发布期），2026-10 月报一发布，golden 里
`period=2026-09` 与 `value=886790.8119340657` 两个锚**立刻同时失效**——那不是
缺陷信号，是 golden 写法错。

因此本单元给入口加了第三个参数 `period`（`YYYY-MM`，空=最新期）：

- golden 用 `period=2026-09` 钉死历史月，锚值永远成立；
- 调度口径不变（`period` 空 → 上一个自然月起探测最新已发布期）；
- 同一参数顺带满足 4.2 的另一项要求「1997 起月报」——任何历史月份都能回补，
  不改代码。

这是相对 tasks.md 原文的**增量**（多一个可选参数），不是收窄：默认行为与
spec 描述一致，增量只为让「锚固定月份数值」与「月更数据」两者同时成立。

## 失败策略

- 目录探测：`[]` = 未发布，继续往回走（上限 `months+4` 次探测）；网络/非 JSON
  错误留痕后同样继续；整个探测窗无任何已发布期 → `RuntimeError`。
- 单表下载/解析失败 → 留痕跳过，其余 7 表照常出数。
- 表号不在 `01..08` 枚举内 → 留痕丢弃（不猜表名）；表号在内但表名漂移 →
  留痕并以表号为准（表号是上游主键）。
- 上游 `-` / `---` / 空 → 该单元格不出行（不写 0，避免把"未披露"伪造成"零"）。
