## ⚠ 索引面登录墙（本源的重大事实，决定本单元怎么点亮）

2026-11-08 03:10 实测：栏目页 `/cat/35/pN.html`、文章页 `/art/<id>.html`、`/robots.txt`、
`/sitemap.xml` **一律 302 → `/account/login`** —— 裸 UA / 浏览器 UA / iPhone UA / http /
https / 带 cookie jar 全都一样。**但 `/sfs/cms/*.pdf` 静态件仍 206 直连可取**
（哈希文件名不随版本变：`81683fdd…` = 行业报告，`826afcda…` = 集团品牌报告）。

因此：

- 本单元提供 `reports="标题=URL,标题=URL"` 参数**直接喂 PDF**，这是当前唯一可用的运行方式；
- 索引发现失败时抛**带解释的** `RuntimeError`（写明「登录墙」+「请用 reports 直给」），
  绝不静默空跑；
- **在索引面重新开放（或拿到凭据）之前，本单元不可点亮 `schedule`** —— 因为自动发现不通，
  只有硬编码哈希 URL 能跑，而下一版报告的哈希必然变化。挂账理由写在这里，不写在别处。

## 字段口径

| 列 | 口径 |
|---|---|
| `report` | `hotel2026` / `group2026`（= 报告文件名的稳定别名，不随年份变） |
| `report_period` | 正文年份（int）；两份报告期次不一致时行级可分辨 |
| `row_kind` | `metric`（散文锚定句）/ `ranking`（序号表逐行） |
| `table` | 见上表；ranking 与同名 metric 表用同一 `table` 值，靠 `row_kind` 区分 |
| `dimension` | 指标的维度标签（全国 / 经济型 / 15-29间 / 一线城市 / 广东 / 前50集团 …）；ranking 恒 `全国` |
| `metric` | 指标 slug；ranking 为 `""` |
| `rank` / `entity_name` / `entity_group` / `entity_hq` | 仅 ranking：序号、集团名或品牌名、所属集团、总部 |
| `value` / `unit` | 指标值与单位，**上游原样**（家 / 间 / 万间 / 万家 / %），不换量纲、不四舍五入 |
| `rooms` / `hotels` | 仅 ranking：客房数与门店数（int） |
| `page` | PDF 页码（1 起），任何一行都能按页复核 |
| `pdf_url` | 行级回溯到源文件（哈希文件名无语义，这是唯一指针） |
| `source` / `scraped_at` | `ctha-hotel-report` / UTC ISO8601 |

## 坑位与容错

1. **索引面登录墙**（见上）：`reports` 直给是当前唯一通路；自动发现失败必须炸，不许静默。
2. **表格逐行只在单元格不折行时取**：前 50 集团表（P9–P10）与外资前 30 品牌表（P13）
   每行一格不缺、序号 1..N 全覆盖 → 整表取；豪华/高端/中端/经济型品牌榜（P14–P18）
   名称与集团单元格跨行折行（`锦江国际酒` + `店`），列归属不可复原 → **整表不取**，
   只取该页无歧义的汇总句，并留痕。**宁缺不错，绝不取半张表**。
   —— 这条由 `parse_rankings` 的「序号 1..N 不全即整表丢弃」硬保证，并有负例测试。
3. **续页不得串榜**：四档品牌榜的序号同样是 1..30/1..20，若按「有 ROOMS/HOTELS 表头就是续页」
   吸收，会把豪华榜的第 1 名当成本表第 1 名。判据加一条：**续页序号集不得与已取行重叠**。
4. **图形页不猜值**：26 个图表页里纯柱状/折线的页（P8 十年序列、P12 31 省排序、P14 前十城）
   抽不出序列 —— 只取同页散文里的极值句，图形本身只在口径里记「图见 PDF 第 N 页」。
5. **概要页要跳过**：hotel2026 有摘要页，数字与明细页有舍入差（如 59.3 万 vs 593,086），
   两份同时进表会出现「同值复现/口径冲突」噪声 → 按标题整页跳过并留痕。
6. **集团榜 ≠ 品牌榜**：`锦江国际酒店` 品牌 23,936 间与 `上海锦江国际酒店股份有限公司`
   集团 1,368,057 间差两个量级；两表各带 `table`，绝**不按名字合并**。
7. **协会口径 ≠ 星级饭店口径**：37.5 万家酒店（本报告）vs 文旅部 6,129 家星级饭店（`mct-star-hotel`）
   是两个宇宙；协会连锁 = 同一品牌 3 家（含）以上门店。**本单元不做跨源合并，只提供对照面。**
8. **`ctha.com.cn` 是死域名**（`000`）；真站 `www.chinahotel.org.cn`。别按协会英文缩写拼域名。
9. **`门店连锁化率\n达28.37%` 被换行切断**：锚定前先把全部空白（含全角空格 / `&nbsp;`）压掉。

## golden 断言口径

`golden/001-ctha-hotel-report.json` 用 `reports=` 直给两份静态 PDF（哈希名不随版本变，
字节数与侦察记录逐字节一致），锚已冻结值：168 行（88 metric + 80 ranking）、
期次 2025、`group_top50` 全 50 行且榜首为锦江 1,368,057 间 / 14,132 店、
`brand_foreign_top30` 全 30 行、外资前 30 汇总 789,099 间、豪华前 20 汇总 287,557 间。
`scraped_at` / `pdf_url` / `page` 入 `whitelist_fields`（`page` 会随 PDF 重排漂移）。

## 历史深度

**只有最新一版**：协会每年只挂当年那一份报告，往年 PDF 不再提供（栏目里是文章不是归档）。
十年序列（2016–2025）只在 P8 的图形页上，无数据标签、不取。要补历史只能等每年新增一版，
或用 `reports` 直给历史哈希（如果别处留存）。
