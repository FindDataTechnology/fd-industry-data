# yindeng-npl-transfer —— 银登中心 不良贷款转让（挂牌 zrgg / 成交 zrjggg）

新源接入档案（批次六·银行业，change `add-banking-industry-sources` 任务 5.3）。

两路公开列表，无 key、无登录、无 Cookie：**挂牌公告**（`zrgg`，项目拟转让）与
**成交结果公告**（`zrjggg`，已签约）。逐条抓详情页 → 附件 PDF → `pdftotext -layout`
文本层 → 按标签抽字段。竖排水印「未经许可不得转载」在 PDF 里逐字散落，抽取前整行/整
token 剔除。

## 端点（从列表页 HTML 与页脚 JS 实读）

| 用途 | URL |
|---|---|
| 挂牌列表 | `https://www.yindeng.com.cn/ywzq/ywzq_bldkzr/bldkzr_xxpl/bldkzr_xxpl_zrgg/` |
| 成交列表 | `https://www.yindeng.com.cn/ywzq/ywzq_bldkzr/bldkzr_xxpl/bldkzr_xxpl_zrjggg/` |
| 列表分页 | `…/bldkzr_xxpl_zrgg/index_<N>.html`（N=1…615）；`index.html` = 最新页 |
| 详情页 | `…/bldkzr_xxpl_zrgg/YYYYMM/tYYYYMMDD_<id>.html`（列表 `a.hrefLink` 给绝对 URL） |
| PDF 直链 | `…/bldkzr_xxpl_zrgg/YYYYMM/P0202…pdf`（详情页 `a` 的 `href`，带 `download`/`sourceName` 属性） |

**CMS 分页是静态文件，没有接口**：

- 页脚 JS 调用 `createPageHTMLApp(总页数, 当前页索引, "index", "html")`——
  实测挂牌 `(616, 0)`、成交 `(303, 0)`；静态子页 `index_<N>.html` 沿用同一函数。
- **每页 10 条**（`rightListContent list-item` 计数实读 = 10）。
  挂牌 616 页 ≈ 6,155 条（与侦察簿 6,155 一致），成交 303 页 ≈ 3,030 条（侦察簿 3,030）。
- **页号方向是反的（实测确认）**：`index_K.html` 是**自旧往新第 K 个静态页**。
  `index_1` → 2021-02/03（最旧），`index_615` → 2026-11-06（挂牌最新静态页），
  `index_302` → 成交最新静态页；`index.html` 是**另一份更新的当前页**（与最高号静态页
  内容不同）。判据：`index_1` 页脚仍写 535 页（生成时的总量），而当前总量 616 页
  —— 旧静态页生成后不再重写，新页只在**高号端**追加。故：

  - 调度口径（`start_page=0`）：`index.html` → `index_(total-1)` → `index_(total-2)`…
    自新往旧翻；
  - 回补/golden 口径（`start_page=N`）：`index_N` → `index_(N+1)`… 自旧往新翻，
    到最新后补 `index.html`。**`index_N` 内容冻结**，这是 golden 能钉死的前提。

## 详情页与 PDF

- 发布时间：`<span>发布时间：2026-11-06</span>`。
  **坑**：2024-12 站点改版后 `/YYYYMM/` 目录与发布时间不同步（实测 `202412/` 目录下

## 竖排水印单字行剔除规则（实测证据）

水印文本是 8 个字 **「未经许可不得转载」**，版面竖排后 `-layout` 会把它拆成：

1. **单字行 / 字间空格行**：`    未`、`    转载`、`                                 经 许`、
   `                                  转 载`、`                           许可`；
2. **粘连形态**：粘在标签前（`未经交易基准日`、`未经项目编号`、`许一、不良贷款基本信息`）
   或粘在数值后（`…0.00             许`）。

规则（`_clean_lines` / `_is_watermark_token`）：

1. 逐行 `split()`，**丢弃「长度 ≤ 4 且每个字符都属于水印字符集 `未经许可不得转载`」的
   token**——单字成行、`经 许` 这类被空格拆开的竖排字串全部命中；
2. 清洗后没有剩余 token 的行整行丢弃；
3. 粘连前缀**不删**：按标签 `search` 定位（`未经交易基准日` 里 `交易基准日` 命中），
   标签与值之间再容忍最多 6 个水印字符（`_GAP`）。
4. 自由文本字段（`五级分类情况`）在段落层再 `strip("未经许可不得转载 ")` 收尾。

**实测效果**（同一份挂牌 PDF）：原始 **184 行 → 剔除 84 行纯水印行 → 76 行正文**，
字符 5,189 → 1,440；成交 PDF 53 行 → 剔除 28 行 → 21 行，字符 1,920 → 418。
剔除后首行即标题，`交易基准日/资产笔数/借款人户数/加权平均逾期天数` 逐行可读，
字段全部命中（见上方样貌与下方首爬数据）。

## 字段抽取规则（全部按标签正则，不依赖列坐标）

| 字段 | 上游标签 / 来源 | 适用 |
|---|---|---|

| `borrower_count` | `借款人户数（户）` | 仅挂牌 |
| `overdue_days` | `加权平均逾期天数` | 仅挂牌 |

`search`，取紧跟其后的值。PDF 里的 `借款人主要区域`、`诉讼情况概述` 等跨行自由文本
不抽（不在本单元字段清单内）。

## 实测取数证据

- 首爬（`limit=2, kinds="", start_page=200`，两路各 2 条）：**4 行 / 13.6 s**
  （9 次 HTTP：2 列表页 + 4 详情页 + 4 PDF，1s 间隔 ≈ 9 s，其余为解析）。
  成交行 `NPL2025003780`、`NPL2025006041`；挂牌行 2024 年建行山西/天津分行项目。
- 单条公告成本 = 2 次请求（详情页 + PDF），1s 礼节间隔 → **约 2 s/条**；
  默认 `limit=100`（两路各 100）= 约 400 次请求 ≈ 7 分钟。
- 覆盖抽检：挂牌 `index.html / 1 / 20 / 60 / 100 / 150 / 200 / 300 / 500 / 601 / 615`、
  成交 `index.html / 200 / 302` 逐页实读，2023 以后页码均抽到全字段，2021/2022 两页为
  扫描件（见上）。

## 为什么 golden 用 `start_page=200` 定页

tasks.md 5.3 要求「golden 锚=已知公告字段组」。默认口径从**最新页**起抓，新公告一发布，
行内容和锚值立刻漂移——那是 golden 写法错，不是数据缺陷（与
`chinabond-monthly` 用 `period` 钉月份同构）。

`index_200.html` 是**生成即冻结**的静态页（页脚总页数实读=当前总量，`index_1` 仍写 535
页即证），因此：

```json
"params": {"limit": 2, "kinds": "", "start_page": 200}
```

两路各取 2 条，恒为同一批 4 条公告：

- 挂牌：建行山西省分行 2024 年第 1 期 → `base_date=2024-05-31`、`loan_count=229`、
  `borrower_count=193`、`overdue_days=226.0`、`unpaid_principal=48355544.56`；
- 成交：中银消费金融 2025 年第 36 期 → `project_no=NPL2025003780`、
  `transferee=昆朋资产管理股份有限公司`、`signing_date=2025-08-11`。

golden 里没有 `transferee`/`project_no` 与挂牌行的交叉规则——挂牌公告确实没有这两个
字段（未成交），`rows_contains` 规则各自独立满足，刻意选了「实抓得到的组合」。
`whitelist_fields` 只放 `scraped_at`。

## 失败策略

- 列表首页不可达 → 该路留痕；两路都空 → `RuntimeError`（不静默回空表）。
- 静态页 `index_N` 404/超时 → 该路停止向旧翻（`start_page=0` 时容 3 次连续失败再停）。
- 详情页失败 / 无 PDF 附件 / PDF 下载失败 / 非 `%PDF` 魔数 / `pdftotext` 失败 →
  **留痕并保留该条的列表元数据行**（`pdf_url` 与数值字段为 `null`），不中断整路。
- PDF 无文本层（扫描件）→ `text_layer=false` + 数值 `null`，绝不伪造。
- `limit` = **每路**行数上限（两路合计至多 `2×limit`）；`kinds` 只接受
  `zrgg`/`zrjggg`，其它值 `ValueError`；`start_page` 真实改变起始静态页。

## 范围与口径备注（需人工确认的点）

- 本单元**未收窄**：两路列表 + PDF 文本层字段全量交付。唯一限制是上游自身形态——
  2021/2022 部分公告 PDF 为纯图片，只能给列表元数据（`text_layer=false`），已如上标注。
- `transferor` 在挂牌侧来自**标题前缀**（PDF 无出让方字段），与成交侧
  `出让方全称` 同源但形态不同，已在 `columns` 描述中写明。
- 季频不良转让统计序列仍无官方公开通道（侦察簿路 10 留痕：官方已调整披露渠道），
  本单元只交付公告级横截面，不注册成长期统计序列。
