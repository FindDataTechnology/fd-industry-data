# dfjc-ratings —— 东方金诚 定期跟踪评级公告（Periodic-tracking）

新源接入档案（批次六·银行业，change `add-banking-industry-sources` 任务 6.4）。

## 端点与参数（2026-11-08 实测）

列表页是**服务端渲染的 HTML 表格**，不是 XHR/JS 渲染，无需浏览器：

```
GET https://www.dfratings.com/Periodic-tracking.html
  ?page=<1-based 页码>      # 分页，10 行/页
  &wd=<关键词>              # 全文检索；任务口径 wd=银行
  &year=<YYYY>              # 公告年份过滤（页面表单未暴露，实测探测所得）
```

页面源码里的搜索表单只声明了 `wd`：

```html
<form action="Periodic-tracking.html">
  <input placeholder="输入关键词" name="wd" value="" type="text"><button>搜 索</button>
</form>
```

分页链接形如 `?page=2`，页脚注释给出总页数 `<!--共1239页-->`。`year` 不在表单里，
是对查询串逐个探测后确认的服务端参数（`year=2025` → 20 页、首行 2025-07-31）。

## `wd` 是服务端过滤（前后条数对比）

同一路径仅改 `wd`，总页数与首行同时变化——若为前端藏行，总页数应保持 1239：

| 请求 | 页脚总页数 | 响应大小 | 首页首行 |
|---|---|---|---|
| `Periodic-tracking.html`（无 `wd`） | **共1239页** | 67,622 B | 四川省乡村发展集团…（非银行） |
| `?wd=银行` | **共99页** | 68,054 B | 浙江浦江农村商业银行…2026-07-31 |
| `?wd=银行&year=2024` | **共15页** | 68,249 B | 江苏淮安农村商业银行…2024-09-30 |
| `?wd=银行&year=2025` | **共20页** | 68,060 B | 威海市商业银行…2025-07-31 |

结论：`wd=银行` 由服务端执行全文检索（1239 → 99 页，约 985 条），不是前端过滤；
`year` 叠加后进一步收窄（2024 年 15 页、2025 年 20 页）。注意 `wd` 是**全文匹配**
而非发行人分类，理论上会命中含「银行」字样的其他文本；本单元按上游返回原样落库，
不在客户端二次过滤（避免把上游判定改成私有口径）。

分页边界实测：`?wd=银行&page=99` 返回 5 行，`page=100` 返回 0 行（HTTP 200，空表）。
`year=2027`（未来年）与 `year=abcd` 同样返回 HTTP 200 的空表，不是 404——代码把
「有效年份无可解析条目」视为空结果，把「表体缺失」视为站点改版。

## 列表形态与字段抽取

表头 6 列，与 `spider.py` 输出字段的对应关系：

```
项目名称            主体等级   债项等级   评级展望   公告时间          下载
project_name        subject_  bond_      outlook   announce_date    pdf_url / pdf_filename
                    rating    rating
```

实读 HTML 片段（`wd=银行&year=2024&page=2`）：

```html
<div class="pjtable">
<table width="100%" border="0">
<tr><td>项目名称</td><td>主体等级</td><td>债项等级</td><td>评级展望</td><td>公告时间</td><td>下载</td></tr>
<tr>
  <td><p class="pj_p elis"><a href="/uploads/files/2024/0802/8u3HxJZ8YFF9RCOA5g5f6pt3Ozq5J5VQCHX6loSv.pdf"
        target="_blank">浙江乐清农村商业银行股份有限公司2023年绿色金融债券(第一期)</a></p></td>
  <!--  <td><p class="pj_p elis"><a href="…同一 PDF…">…同一标题…</a></p></td>  -->
  <td>AA+</td><td>AA+</td><td>稳定</td>
  <td><span style="white-space:nowrap;">2024-07-30</span></td>
  <td><a href="/uploads/files/2024/0802/8u3HxJZ8YFF9RCOA5g5f6pt3Ozq5J5VQCHX6loSv.pdf"
         download="浙江乐清农村商业银行股份有限公司主体及相关债项2024年度跟踪评级报告.pdf" class="pj_dw"></a></td>
</tr>
```

**硬坑 1（列错位）**：每个数据行的项目名称后都跟一段被 `<!-- -->` 注释掉的重复
`<td>`。直接按 `<td>` 计数会得到 7 列并导致全部字段右移；必须先剔除 HTML 注释
再切行（首轮实测即踩中）。

**硬坑 2（上游错字）**：等级字段存在原文错字，实测 `AA_`（宁波奉化农商行 /
浙江平湖农商行，2024 年页）。本单元**原样保留**，不做等级归一化——归一化会掩盖
上游质量问题并让 golden 失真。

抽取规则：

- 标题/PDF 链接取第 1 个单元格里的 `<a href>`；`html.unescape` 后去标签、压空白。
- PDF 直链拼成绝对 URL：`/uploads/files/YYYY/MMDD/<token>.pdf` →
  `https://www.dfratings.com/...`。
- `pdf_filename` 取下载列 `download="…"` 属性（即报告文件名）。
- 公告类条目（标题为「东方金诚关于…公告」）的主体/债项等级与展望为空，**保留空串**
  而不是丢行——这类条目本身是有用的跟踪行动记录。
- 行内 `keyword`/`year`/`page` 记录本次请求口径，便于回溯与去重。
- 以 `pdf_url` 去重（翻页期间列表若插入新条目，避免同一公告重复落库）。

**无详情页**：项目名称直接链到 PDF，列表即详情；本单元只抓列表元数据，不解析
PDF 正文。

## 实测取数证据

- golden 口径 `limit=100, keyword=银行, pages=3, year=2024`：
  **30 行 / 4.8s**（3 次列表请求，每次 0.6–0.8s；2 次 ≥1s 间隔，`SLEEP=1.2`）。
  分页 10+10+10 行，页码字段分别为 1/2/3。
- 首爬默认口径 `limit=200, keyword=银行, pages=3`（全量滚动列表）：同为 **30 行**，
  同页数耗时约 4.8s。
- 单页响应：HTTP 200，`Content-Type: text/html; charset=UTF-8`，约 68 KB，
  10 行/页；最新银行条目为 2026-07-31，列表按 `公告时间` 降序。
- `year=2025` 末页（page=20）9 行，即 20 页共 199 条；`wd=银行` 全量 99 页、
  末页 5 行，共 985 条。两处均证明页码 1-based、每页 10 行。

## 为什么 golden 用 `wd=银行&year=2024` 钉住

银行列表是**滚动列表**：每年 7 月跟踪评级报告集中发布并插到最前，页码整体后移
（2026-11-08 时 `wd=银行` 第 1 页已是 2026-07-31 的条目）。若 golden 锚「当前第 1 页」，
下一年度报告一发布立刻失效。

因此本单元给入口加了第 4 个可选参数 `year`（服务端过滤，空串=全部年份）：

- golden 用 `year=2024` 钉住**已闭合年份**——该年份的 15 页列表不再被新年份公告
  插入，只在极少数更正公告出现时顶部微动；锚点取第 1/2/3 页共 3 条：
  - 第 1 页更正报告：`江苏淮安农村商业银行…（更正）（以此为准）` / 2024-09-30 /
    主体 AA / 债项 AA-；
  - 第 2 页：`浙江乐清农村商业银行股份有限公司2023年绿色金融债券(第一期)` /
    2024-07-30 / AA+ / AA+ / 稳定 / PDF `…/2024/0802/8u3Hx…pdf`；
  - 第 3 页：`日照银行股份有限公司2022年绿色金融债券` / 2024-07-30 /
    PDF `…/2024/0730/y7Dp3…pdf`。
- 默认口径不变（`year` 空 → `wd=银行` 全量滚动列表、最新在前），调度行为与任务
  原文一致；`year` 只用于历史回补与 golden 固定，属**增量**而非收窄（同
  `chinabond-monthly` 的 `period` 先例）。

## 失败策略

- 单页请求失败（超时/URLError/OSError）→ 留痕后继续下一页；所有页均失败且无表体
  → `RuntimeError`。
- 单页找不到 `pjtable`/`</table>`（疑似改版）→ 留痕跳过；全部页均无表体 →
  `RuntimeError`。
- 表体可解析但 0 行（到底、该年份无公告）→ 记日志并停止翻页，返回 `[]`；不把
  「上游合法空集」伪装成异常。
- 行结构不是 6 列 → 留痕丢弃该行，不猜列位。
- 等级/展望缺失 → 空串，不写 0、不推断等级。
- `year` 非空但不是 4 位数字 → `ValueError`（在请求前拦截）；`limit<=0` 或
  `pages<=0` → 返回 `[]`。
- 请求间隔 1.2s（任务要求 ≥1s），翻页到空页/超出 `共N页`/达到 `limit` 即停。
