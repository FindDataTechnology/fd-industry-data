## 月份表头「数字截零」坑（本单元最关键一处）

实测表头（2026-10 发布的一期）：

```
2026.01  2026.02  …  2026.09  2026.1  2026.11  2026.12
```

中间那个 `2026.1` **是 10 月**——小数尾零被截掉了，不是 1 月。若按 `float()` 或
`int(月)` 朴素解析，10 月数据会**落在 1 月**并污染整条年度序列（且 1 月本来就是
`2026.01` 已占位，冲突是静默的）。

`_parse_month()` 按**小数位宽度**还原：一位小数 → ×10（`2026.1`→10 月），
两位 → 原值（`2026.01`→1 月）；越界回退原值并做 1..12 校验。

## 指标名口径

单元格是中文 `\xa0`（另有全角空格 `\u3000`）中英双行：
`一、各项存款\xa0Total Deposits`。`_indicator_name()` 按 `\xa0 / \u3000 / ·` 分段，
取**第一个含中文的段**，英文半与缩进空格一并丢弃；`indicator_level` 由序号形态派生
（`一、`=1 / `（一）`=2 / `1.`=3 / `（1）`=4，无序号总计=0）。
行首 5 行标题/单位/英文副标题噪音不做定位依赖——表头行按「含『项目』且含月份标签」找。

## 原位替换与序列积累（重要设计边界）

栏目页**只有最新一期**，历史月份不在栏里（更早年度栏目页各自只留该年末快照；
在线深度止于 2016）。所以：

- 本单元每次运行取到的是**最新一期的全部月份列**（实测一期含 2026-01…2026-09 共 9 个月）；
- **逐月序列靠平台按月累积**，不是每次重爬历史；
- 需要历史回补时按年度栏目页取年末快照，那是一次性离线动作，不在排期路径上。

## 坑位（侦察簿路 3，逐条落实位置）

1. 月份表头截零 → `_parse_month()`（见上）。
2. `sharedStrings` 带 `\xa0` 中英双行 → `_indicator_name()`；`\u3000` 全角缩进同处理。
3. 首 5 行噪音 → 表头按内容定位（`项目` + 月份标签），不写死行号。
4. 行尾 `注：…` 脚注段无值 → 由「无有效值不产行」自然跳过（不额外判别）。
5. 年度栏目滚动 → `column_url()` 从索引动态取**最新年度**，跨年不需改代码。
6. 栏目在线深度止于 2016 → 不做深翻；历史回补是离线动作（见上）。

## 失败策略

单表失败 → stderr 留痕并继续其余表；九表全空 → `RuntimeError`；
空单元格**绝不填 0**（只跳过）；`limit` 真实生效且九表**轮流取行**，
截断时仍覆盖全部表而不是把预算全给第一张。
