### 1. Scraping Framework
- Primary: Scrapling Fetcher with Chrome impersonation

### 2. Data Storage
- SQLite: Idempotent INSERT OR REPLACE operations
- JSON: Export by category for easy analysis
- Schema: Standardized with common fields (date, value, unit, period)

### 3. URL Configuration
```python

```

### 4. Extraction Functions
- `init_db()` - Initialize SQLite tables
- `fetch_page(url)` - Fetch with error handling
- `extract_date(text)` - Normalize date formats
- `extract_number(text)` - Parse numeric values
- `get_{slug}_data()` - Main entry point

## Known Parsing Challenges

### 1. Pagination
Some sites use JavaScript pagination not fully covered yet:
- Most government portals
- Some commodity exchanges

### 2. Dynamic Content
Charts/data rendered via JavaScript:
- Need Playwright fallback for some pages
- Current implementation captures static content

### 3. Login Walls
Premium data behind login:
- Wind, iFinD, Eastmoney have subscription tiers
- Public summaries scraped; detailed data requires API keys

### 4. Table Format Variations
Different layouts across sections:
- Generic parsers try multiple patterns
- May miss edge cases

### 5. Chinese Units
Handling 万，亿，etc.:
- Normalization attempted but may need refinement
- Unit columns included in schema for reference
